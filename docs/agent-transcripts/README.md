# Agent transcripts

The repository snapshot available for this submission contains no genuine coding-agent conversation logs or transcripts. No conversations or failed attempts have been reconstructed or fabricated here.

To add logs, place original coding-agent session exports in this directory. Before committing, remove API keys, passwords, personal data and other sensitive material; preserve enough surrounding context to understand any redaction. Include a short note with each export identifying the tool and date if that information is available. Do not label manually written summaries as raw transcripts.
